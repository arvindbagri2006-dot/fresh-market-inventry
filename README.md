# FreshCart — E-commerce + Inventory Demo

A responsive single-page storefront and inventory dashboard built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build step is required.

## Features
- Search and category filters
- Product cards and add-to-cart demo
- Inventory KPIs and stock status
- Add/edit products and adjust stock quantities
- Responsive layout

## Deploy to Vercel with GitHub
1. Create a GitHub repository (e.g. `freshcart-inventory`).
2. Upload `index.html` and `README.md` to the repository root.
3. Sign in to Vercel and choose **Add New → Project**.
4. Import the GitHub repository; select **Other** or leave framework preset unset.
5. Keep build command and output directory empty/default for this static site, then deploy.
6. Copy the production URL from Vercel.

## Important limitation
This is a front-end demo. Product edits and stock adjustments are in-memory and reset on refresh; real multi-user inventory requires a database and authentication.
